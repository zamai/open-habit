# Contributing to Open Habit

I'm Alex, a software engineer, but not an iOS developer. I'm vibe coding this project with AI agents, learning as I go, and sharing the result with other people who want to improve their habits.

There are probably things here that an experienced iOS developer would do differently. If you know what you're doing and see something worth fixing, please submit a PR or [open an issue](https://github.com/zamai/open-habit/issues). I'd appreciate the help.

You don't need to write code to contribute. If something breaks, feels confusing, or gets in the way of building your habits, tell me. For bugs, include what happened, what you expected, and how to reproduce it if you can. Please keep personal habit data and credentials out of issues and screenshots.

I'm leaving the build and run instructions to your agents. Hopefully they'll be able to figure out how to get the project running from what's in the repository.

Keep PRs focused and explain what you changed and how you checked it. For a bigger feature, open an issue first so we can talk it through before you spend time on it.

By contributing, you agree that your contribution is licensed under the repository's [MIT license](LICENSE).
